s8ga package repository

Flat APT repository hosting s8ga's Debian packages, built automatically from upstream releases. Unsigned, served over HTTPS from GitHub Pages.

Add the repository (Debian / Ubuntu)

echo "deb [trusted=yes] https://s8ga.github.io/repo/deb/ ./" \
  | sudo tee /etc/apt/sources.list.d/s8ga.list
sudo apt update

Then install any package listed below, e.g. sudo apt install tailscale-derper-oauth.
